# Local Usage

Clone repo

```shell
cd ~/.vscode/extensions/
git clone https://github.com/wlchn/vsc-awesome-dark-theme.git
```

VSCode `cmd`+`shift`+`P`

```
Developer: install extension from location
```

To show hidden files in Finder: `cmd`+`shift`+`.`

Select `vsc-awesome-dark-theme`
